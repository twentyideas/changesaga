# Shipping, trust, and quality {#shipping-trust-quality}

This chapter follows the public artifact from an authorized Git tag to a user-owned executable, then shows the checks and operating promises that make that path reviewable. It owns release automation, installers, the browser and large-saga test harnesses, detached reviewer lifecycle, and the repository’s public contribution/support contract. Product format and AI-query implementation are explained in their own chapters.

The comparison is since inception: base `14afd0526c471d9ccad5825fadda735094e599e4` contains none of these tracked files, while `v0.0.6` is the cumulative release assembled by the intervening commits. The evidence therefore describes the v0.0.6 system as introduced, not merely the last tag’s changelog delta.

Review the tag-to-install map first. The following sections recurse into the trust boundaries behind each arrow, the harness that attacks them, the managed local-review process, and the limits that remain external or deliberately unverified.
