# From explanation to exact evidence {#linked-evidence}

The page evaluates the product comparison once, indexes covered atoms by target, and builds each rendered fragment with only its owned changes.[^target-index] A landmark or citation therefore opens a focused drawer whose rows stay grouped by source file; the collapsed file summary is assembled from the mapping notes that actually match those atoms.[^drawer-summary]

Opening a file in Code Diff or from narrative evidence invokes the same review-file-diff surface and hydration path. That shared hydrator automatically streams every bounded diff page so all changed hunks are present without a `Load more` gate. Each server response stays capped at fifty rows, while Git supplies at most twenty unchanged lines around each hunk; the cumulative open surface therefore contains every changed row plus bounded context, not an arbitrary whole source file. This deliberately trades cumulative rendering for immediate access to every changed hunk. Fetching deeper omitted gaps would require a separate old/new range contract.

As pages arrive, the surface reports loaded and total rows and highlights each batch. Closing the file or drawer cancels its consumer, and repeated cursors fail instead of spinning from cache. After the final page arrives, unchanged rows collapse behind controls that reveal the next ten lines, previous ten lines, or all currently available context; keyboard focus remains on the acted control when it survives, while row selection, comments, suggestions, layout, and linked-evidence attribution remain attached to the same rendered rows.[^drawer-hydration] Authored Markdown is rendered as safe GFM with explicit namespaced heading IDs, while raw HTML is escaped rather than trusted.[^safe-markdown]

[^target-index]: Page construction derives a per-target atom index from evaluated coverage before fragment views are rendered.
[^drawer-summary]: Attached-code projection groups exact atoms by file and derives each collapsed summary from matching authored evidence notes.
[^drawer-hydration]: The browser fetches the complete file diff on first expansion and highlights the rows already linked by the narrative target. Code Diff and the narrative drawer invoke one shared surface template and guarded hydrator, including row actions, selection tools, context folding, bounded-page streaming, cancellation, and cursor validation.
[^safe-markdown]: Markdown rendering enables GFM and footnotes, namespaces stable headings, and escapes authored raw HTML.
